# AI-Boyfriend-Timeline-
Visualizing the timeline of relationships with AI Companionships 

May 19th: V1 - Visualizations
Organizing data to see patterns and gain inspiration for more intricate visualization opportunities. 

Spiral Timelines:
- for each individual participant, showing the evolution of thier relationship 
- Filter for Phases
- Dropdown filter for Milestones
- Hovering over an event displays the phase name, milestone, and quote.

Sankey Diagram 
- Shows the large trends across timelines.
- Each node shows a different step in the relationship, grouped by phases, so you can see how they evolved.
- The colour represents the phase
- Hovering over a node displays the Phase, Milestones, and ID's of people involved
- Hovering over a link displays the transition (from which phase to which) and the individual ID
